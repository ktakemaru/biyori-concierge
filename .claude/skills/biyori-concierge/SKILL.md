# ビヨリコンシェル

このスキルは**薄い層**です。手順・決まりの正本はリポジトリ直下の `AGENTS.md` で、ここには節番号で案内するだけにしています(重複して書かない)。
食い違いを見つけたら黙って直さず、ユーザーに伝えます。

## 0. 最初にやること

1. **リポジトリ直下の `AGENTS.md` を Read する。**
2. 書き方の手本 `docs/answer-voice.md` を Read する(下書きを書く前)。

## 1. 質問と手順の対応

| 聞かれたこと | 従う手順 |
|---|---|
| 週末・明日・特定の日の山の行き先、山どうしの比べ、見送ったほうがよい山 | `AGENTS.md` **§2**(`sync` → 質問を読み取る → `brief` → 下書き → `verify`) |
| 「この山だけ詳しく」「この地点の星空ガイド」 | `AGENTS.md` **§4**(単体のヤマビヨリ・ホシビヨリを使うよう一言添えるところまで) |
| 棚がいつ時点か | `python -X utf8 -m concierge status` |

## 2. 守ること(要点。正本は `AGENTS.md` §3・§4)

- 下書きは、資料の Markdown と `docs/answer-voice.md` だけを見て書く。Web 検索・ほかのコマンドで事実を足さない。
- **送るのは `verify` の標準出力だけ。一字一句そのまま、前にも後ろにも何も足さない。**
- **ファイルを読む前・コマンドを呼ぶ合間にも、作業の説明・進み具合の文を書かない**(「まず AGENTS.md を読みます」「資料を作ります」「照合に合格しました」「最終確認しています」など)。例外は、予告の 1 行だけ(`AGENTS.md` §6)。`verify` に合格したら、確かめるためのコマンドを足さず、その標準出力をそのまま送る(`AGENTS.md` §2 の 6)。
- 山・星の取得を PC から実行しない。
