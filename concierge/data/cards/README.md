# 知識カードの置き場(段階 2 は仕組みだけ。本物のカードは 0 枚)

1 枚を 1 つの YAML にする(`<名前>.yaml`)。資料(`brief`)は、事実の山の ID が `targets.mountains` に入っているカードだけを入れる。

```yaml
id: <変わらない名前>            # 例 closure-0001
targets:
  mountains: [m001]             # 対象の山の ID(ヤマビヨリの MOUNTAINS の id)
  kinds: [closure]              # 種類(季節の通行止め・ロープウェイの運行の時期など。任意)
text: <答えに書いてよい 1〜2 文>
say: [<書いてよい数字・日付の表記>]   # 任意
source:
  name: <出典の名前(公式のもの)>
  url: <出典の URL>
checked: 'YYYY-MM-DD'           # 出典で確かめた日
```

- 山についての知識(難しさ・装備・ルート・見どころ)を、出典なしに書かない(段階 2 の作業指示書 2 章)。
- 「判断を変える知識」(季節の通行止め、ロープウェイの運行の時期など)から足す(開発指示書 6.2)。
- テスト用の作り物のカードは、テストの中で一時フォルダに作る(`BIYORI_CONCIERGE_CARDS_DIR`)。
