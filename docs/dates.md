# 日付の規則(`concierge brief --when …`)

日付計算は LLM にさせず、`brief` が `--when` と `--now` から決める(日本時間、オフセットつき)。コードは `concierge/dates.py`。

元は biyori-hub の `docs/dates.md`(commit `102700e`)と `hub/core/dates.py`(commit `97e678c`)。`weekend` の規則はそのまま写し、
`来週末`・`明日`・日付・範囲を足した(hub の `tonight`・`days N` は使わないので写していない)。写した記録は `docs/ported-from-hub.md`。

| `--when` | 規則 | 日 |
|---|---|---|
| `今週末`(既定。`週末` も同じ) | **土曜**に実行 → 当日の土〜日。**日曜**に実行 → 当日の日のみ。**平日(月〜金)**に実行 → 次の土〜日(hub の `weekend` と同じ) | 1〜2 日 |
| `来週末` | 「今週末」の土曜の 7 日後の土〜日。**日曜**に実行したときは、次の土〜日(今週末は今日だけなので) | 2 日 |
| `明日` | 今日の次の日 | 1 日 |
| `YYYY-MM-DD` | その日 | 1 日 |
| `YYYY-MM-DD..YYYY-MM-DD` | 両端を含む範囲(31 日まで。仮置き) | 範囲の日数 |

- 「今日」は `--now`(なければ今の時刻)を日本時間にした日付。`--now` にオフセットが無ければ日本時間とみなす。
- 各日の時間の幅は 00:00〜23:59(+09:00)。資料には日付・曜日・ラベル(`11月21日(土)`)を入れる。
- 対象の日に棚の予報が無いとき(棚が古い・14 日より先)は、資料の「足りないもの」に入る(止めない)。
