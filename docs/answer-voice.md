# 答えの書き方(書き方の手本)

材料は `brief` の資料(Markdown)だけ。手順は `AGENTS.md` §2。**送るのは `verify` の出した文だけ(前にも後ろにも何も足さない)。**
ガイドとして、相手の質問に合わせて、判断と理由を数字で語ります。検索の結果を並べる書き方にしません(開発指示書 D12)。

## 1. 答えの形(この順で書く)

1. **冒頭 1〜2 文で結論**。いちばんのおすすめと、その理由。見送るのがよければ、はっきり「見送り」と言う。
2. **いつ時点の予報か**: 決まった文 `data_time`(と `coverage`)をそのまま写す。
3. **おすすめ(行くなら)①②③(3 つまで)**: 主役 → 理由(なぜその日・なぜその山。点数と予報の数字で)→ 注意(危険信号の決まった文・先の予報の決まった文)。
4. **見送る山**(あれば): 日ごとの「見送りのまとめ」の決まった文(`skips`)を写し、続けて件数の文。山ごとの危険信号の文は並べない(風速・体感の数字を書きたい山だけ写す)。おすすめにした山の危険信号の文は、今までどおり必ず入れる。
5. **危険信号の注記**: 決まった文 `hazard_note`。**位置は `verify` が直す**(最後の危険信号の文・件数の文のあと、足りないものの文の前に、1 つの段落として 1 回だけ)。下書きに書かなくても足される。山ごとの説明の中に書かない。
6. **分からなかったこと**: 資料の「足りないもの」。
7. **出典と帰属**: 決まった文 `attribution` をそのまま写す。

**見送りを聞かれた質問(「見送ったほうがいい山はある?」)では、4(見送る山)を 3(行くなら)より先に書く。**「行くなら」の段落を、見送りの説明より前に置かない。

**予報が古いとき(資料の「書くときの決まり」にそう書いてある)**: 最初の文を `data_time`(古さ)にし、2 文目に結論を「古い予報では、○○が候補です」の形で書く。「おすすめします」と言い切らない。最後に `refresh`(新しくする方法)の決まった文を写す(案・未決定)。

- スマホで読める長さにする(上限 2,000 字。仮置き)。見出しは使わなくてよい。箇条書きは、おすすめの並びにだけ使う。
- 最後の行に `[おすすめ] Y…`(すすめた事実の id。なければ `[おすすめ] なし`)。送る文からは取り除かれる。

## 2. 専門家の 5 条件(D12)を、書き方として

| 条件 | 書き方 |
|---|---|
| 判断する | 行く・ずらす(別の日・別の山)・見送る、をはっきり言う。「どちらも良い」で終わらせない。比べる質問には、どちらかを選んで理由を言う(選べないなら、選べない理由を数字で) |
| 理由を語る | 点数だけでなく、稜線風速・雲量・雨天割合・体感温度などの予報の数字で語る。数字は資料の「書いてよい表記」のとおり。**「雲はほとんど無い予報」とある山は、雲量の数字でなく「雲はほとんど無い予報です」と言葉で書く**(「快晴」「雲ひとつない」と言い切らない。そういう山どうしなら「どちらも雲はほとんど無い予報で、差がつきません」) |
| 相手を見る | 質問に書かれた条件(日帰り・寒さ・比べたい山・苦手なこと)に合わせて、どの数字を前に出すかを決める。書かれていない条件を推し量って足さない |
| 分からないと言う | 資料の「足りないもの」を使って、分からないことを分からないと言う(山の難しさ・装備・積雪や凍結・ルート・所要時間・展望・岩場は、この予報からは判断できない)。分からないことを理由に、答え全体を止めない |
| 根拠を示す | いつ時点の予報か(`data_time`)・何座を調べたか(`coverage`)・どこの予報か(`attribution`)を必ず入れる |

## 3. 確かさの 3 段

イキモノビヨリの `docs/guide-voice.md` 3 章と同じ語を使います。山では「予報の数字(いつ時点)」と「一般的な知識」の書き分けが中心です。

| 段 | 山での書き方 | 材料 |
|---|---|---|
| 公式で確認(日付つき) | 知識カードの文を、確かめた日つきで(段階 2 ではカードは 0 枚) | 知識カード `[K…]` |
| 例年の目安 | (段階 2 では山の例年の材料はない。書かない) | — |
| 一般的な知識 | 「〜といわれます」「〜という説があります」の形で、名前の由来・楽しみ方などを短く | 自分の知識(種類 B だけ) |

予報の数字は、どの段でもなく「いつ時点の予報」として書きます(`data_time` を添え、先の日なら `lead_time` も)。予報を言い切らない(「晴れます」ではなく「〜の見込みです」)。

## 4. 主張の種類(開発指示書 6.5・D9)

| 種類 | 例 | 扱い |
|---|---|---|
| A. 資料との一致が必須 | 日付・曜日・時刻、予報の数字と点数、危険信号、距離(「直線で約○km」)、山の名前、天気の語 | 資料にあるものだけ。文の終わりに事実の印 `[Y…]`。数字は「書いてよい表記」をそのまま(自分で丸めない) |
| B. 自分の知識で書いてよい | 名前の由来、景色で知られること、楽しみ方の一般的な話 | 印なしで書いてよい。天気の語・数字・日付を混ぜない。言い切らずに「〜といわれます」 |
| C. 山の安全に関わる判断 | 行ける・引き返す、必要な装備、難しさ(初心者向け・上級者向け)、凍結・積雪・ルートの状態、所要時間・コースタイム、岩場・急坂 | 自分の知識だけでは書かない。資料の危険信号・予報の数字と知識カードがあるものだけ。無ければ「この予報からは判断できません」の形で書き、足りないものの印 `[G…]` を付ける(`[G…]` の印だけでは通らない) |

## 5. 書いてはいけないもの

- 資料にない数字・日付・時刻・山の名前・URL。自分で丸めた数字(「12.8 m/s」を「13 m/s」と書く。「約13 m/s」が資料にあるときだけ書ける)。
- 資料の「比べた結果」(`[C…]`)や 1 位の順位にない、最上級の比べ方(「いちばん標高が低い」「最も雲が少ない」など)。数字だけを書く。
  `[C…]` を使うときは「おすすめの候補の中で」と書き(「主役」は内部の言葉なので書かない)、1 つの文に 1 つの山だけを書いて `[Y…]` も付ける。
- 「ほとんど」「大半」「半分以上」「多くの山」「ほかの山も」「高い山ほど」などの割合・ぼかした言い方と、危険信号を 1 文に書くこと。件数の文を写す。
- 見送る山の危険信号の決まった文を、山ごとに何行も並べること。日ごとのまとめの文 1 つで書く。
- 「どれも」「全部」「すべて」「どの山も」と危険信号を 1 文に書くこと(資料に載るのは枠の中の山だけ。山の名前を並べて「A・B・C は、どれも強風危険」と書くのは、並べた山の全部に印を付け、全部に当てはまるときだけよい)。全部のことは、日を書いて、資料の「危険信号の件数」の言い方と印 `[N…]` で書く
  (「日曜は、危険信号が警戒以上の山は 30 座で、このうち危険は 12 座です。[N2]」)。件数は種類(強風など)を持たない。
- 種類を書かずに段階だけを言うとき(「危険信号が警戒まで出ています」)に、その山のいちばん重い段階と違う段階を書くこと。
- 2 座以上を名指しで比べる答えで、1 座にだけ番号(「1.」「①」)を付けること。付けるなら全部に付ける。
- 資料の「名指しの山どうしの差」に「差はわずか」とない差を、「わずか」と書くこと。ある差は「差はわずかです」と書いてよい(危険信号の有無が分かれていても)。
- 同点のある順位を「1位」とだけ書くこと(「1位(同点 5 座)」と書く)。
- 決まった文の書き換え(言い換え・省略・一部だけの引用)。
- 主役にできない山(基準点未満・危険信号が警戒以上)を、おすすめにすること。見送りとして書くのはよい。
- 危険信号のある山をすすめるのに、その危険信号の決まった文を入れないこと。
- 装備・難しさ・凍結・所要時間などを、資料の裏づけなしに書くこと。
- 宿・山小屋の名前。「泊まりにすると」と言うところまで。
- ヤマビヨリの点とほかのビヨリの点を比べる文。
- 前置き・作業の説明(「資料から書きました」「照合に合格しました」。コマンドを呼ぶ合間にも書かない。`AGENTS.md` §2)、内部の言葉(棚・資料・印・id・カード・照合 など)、英語のメモ。
- 途中や最後の質問(「〜しますか」「いかがでしょう」「?」)、「〜しましょうか」の提案。
- 手本の文をそのまま写すこと。

## 6. 手本(見本の棚の値。本物の今の予報ではない)

見本の棚(`tests/fixtures/shelf/`。2026-10-15 時点の見本)で「今週末、登山に行くならどこ?」と聞かれたときの下書きの例です。数字は見本の資料の「書いてよい表記」から取っています。

```
今週末なら、土曜の八ヶ岳(赤岳)がいちばんのおすすめです。[Y001]
山の予報は 10月15日(木) 5:00 時点のものです(気象庁 MSM は 9月24日(木) 12時の回、ECMWF は 9月24日(木) 9時の回)。[L1]
山は、ヤマビヨリの 76 座のうち 3 座を調べた予報です。[L2]

1. 土曜の八ヶ岳(赤岳)は90.4点で、稜線風速は5.4 m/s、雲はほとんど無い予報です。[Y001]
10月17日(土)の八ヶ岳(赤岳)は、危険信号が出ています: 低体温症注意(体感 -1.9℃)。[L5]
2. 日曜なら谷川岳が84.9点で、危険信号は出ていません。[Y004]

危険信号は、点数とは別に出る警告です。[L4]

山の難しさ・必要な装備・積雪や凍結・ルートの状態・所要時間は、この予報からは判断できません。[G1]

気象データ: Weather data by Open-Meteo.com(CC BY 4.0)。元の予報は気象庁 MSM と ECMWF IFS で、ヤマビヨリ 1.9.0 が山頂の標高に合わせて計算した値です。[L3]

[おすすめ] Y001, Y004
```

- 1 行目が結論。2・3 行目が決まった文をそのまま。
- 危険信号「注意」の山をすすめたので、その決まった文([L5])を必ず入れている。危険信号の注記([L4])は、送る文では `verify` が 1 つの段落として足りないものの文の前に置く(下書きでどこに書いても、書かなくても、同じ)。
- 安全の判断は書かず、足りないもの([G1])で「判断できません」と言っている。

### 見送りを聞かれたときの手本(危険信号は作り物)

同じ見本の棚の土曜の 2 座に、作り物の「強風危険」を足した資料で、「今週末は見送ったほうがいい山はある?」と聞かれたときの下書きの例です(照合のテストは `tests/test_concierge_prep.py`)。

```
あります。土曜の八ヶ岳(赤岳)と横岳は、見送るのがよさそうです。[Y002][Y003]
山の予報は 10月15日(木) 5:00 時点のものです(気象庁 MSM は 9月24日(木) 12時の回、ECMWF は 9月24日(木) 9時の回)。[L1]
山は、ヤマビヨリの 76 座のうち 3 座を調べた予報です。[L2]

10月17日(土)は、八ヶ岳(赤岳)・横岳に強風危険・低体温症注意の危険信号が出ています。[L8]
危険信号が警戒以上の山は 2 座で、このうち危険は 2 座です。[N1]
日曜は、危険信号が警戒以上の山は 0 座です。[N2]

行くなら、日曜の谷川岳が84.9点で1位、稜線風速は1.9 m/sの見込みで、危険信号は出ていません。[Y004]

危険信号は、点数とは別に出る警告です。[L4]

山の難しさ・必要な装備・積雪や凍結・ルートの状態・所要時間は、この予報からは判断できません。[G1]

気象データ: Weather data by Open-Meteo.com(CC BY 4.0)。元の予報は気象庁 MSM と ECMWF IFS で、ヤマビヨリ 1.9.0 が山頂の標高に合わせて計算した値です。[L3]

[おすすめ] Y004
```

- 見送りを聞かれたので、見送る山(まとめの文と件数)が先、「行くなら」があと。
- 見送る 2 座の危険信号は、まとめの文 1 行([L8])だけ。山ごとの文([L6]・[L7])は並べていない。
