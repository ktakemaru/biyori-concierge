## 9. 次の段階(段階 3)の前に要ること

- **H2(聞かれた夜を必ず調べる)**: 資料は「対象の日の予報が無ければ足りないものに入れる」形で作った。星でも同じ形にできるが、その夜の雲量が棚に無いと「分からない」しか言えない。山で、上位の枠が使えない山で埋まって主役が消えたのと同じことが、星では「月の条件の良い上位 6 夜」で起きる。聞かれた夜が上位に入らないときの扱いを、段階 3 の第 1 部で決める必要がある。
- **H3(星の地点の変わらない ID)**: 資料の事実の id・組み合わせ(`plans` の `adds`)・照合の地名の検査は、山の ID と 76 座の名前の一覧(資料の `mountain_index`)を頼りにしている。星の地点も、変わらない ID と名前の一覧が棚に要る(名前と緯度経度だけでは、資料にない地点の名前を照合で見つけられない)。
- 照合の「天気の語」は星の答え(雲量・晴れ間)でも同じ形で使える。ビヨリ間で点数を比べる文の検査(`score_across_biyori`)は作ってある。
- 決まった文 `data_time` は今「山の予報は…」。星を足すときは、星の予報の時点を別の文にする(開発指示書 6.2 の例の「山と星の予報は」の 1 文にするか、2 文に分けるか)。
