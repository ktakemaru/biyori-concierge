## 書くときの決まり

- 答えの形: 結論(1〜2文)→ いつ時点の予報か([L…] をそのまま)→ おすすめ(行くなら)3 つまで(理由は数字で。注意)→ 見送る山(まとめの文と件数)→ 危険信号の注記 → 分からないこと → 出典([L…] をそのまま)。見送りを聞かれたら、見送る山を先に、「行くなら」をあとに書く。
- 数字・日付・曜日・山の名前・危険信号を書いた文の終わりに、根拠の事実の印 [Y…] を付ける。書いてよい表記は事実の「書いてよい表記」だけ(自分で丸めない)。
- 決まった文 [L…] は一字一句そのまま写し、終わりに印を付ける。
- 天気の語(晴れ・雲・風・雨・雪・霧・見通し など)を書く文には、必ず事実の印を付ける。
- 山の難しさ・装備・積雪や凍結・ルート・所要時間は書かない。聞かれたら「足りないもの」[G…] を使って、「この予報からは判断できません」の形で書く([G…] の印だけでは通らない)。
- 「いちばん」「最も」などで風・距離・点数を比べる文は、比べた結果 [C…] か、順位が 1 位の事実だけで書く。[C…] は「候補の中で」と書き、その山の事実の印 [Y…] も付ける。ほかの比べ方はしない(数字だけを書く)。
- 「どれも」「全部」「すべて」「どの山も」と危険信号を 1 文に書かない(山の名前を並べて「A・B・C は、どれも強風危険」と書くのは、並べた山の全部に印を付け、全部に本当に当てはまるときだけよい)。日ごとの件数は、危険信号の件数 [N…] の「書いてよい言い方」で書く(資料に載っている山は枠の中だけなので、全部のことは件数でしか言えない)。
- 「ほとんど」「大半」「半分以上」「多くの山」「ほかの山も」「高い山ほど」などの割合・ぼかした言い方と危険信号を 1 文に書かない。件数の文を写す。
- 見送る山の危険信号は、日ごとの「見送りのまとめ」の決まった文を写して書く(続けて、件数の文)。山ごとの危険信号の文は、風速・体感の数字を書きたい山だけ。おすすめにした山の危険信号の文は、まとめの文があっても必ず要る。
- 危険信号の注記の決まった文は、verify が正しい位置(最後の危険信号の文・件数の文のあと。足りないものの文の前)に 1 回だけ置く。下書きに書かなくてよい(書いても 1 回に直る)。
- 名指しの山どうしの差(資料の「名指しの山どうしの差」[C…])に「差はわずか」とあるときは、危険信号の有無が分かれていても「差はわずかです」と書ける(その [C…] と両方の山の [Y…] の印を付ける)。「差はわずか」は、この印があるときだけ書く。
- 2 座以上を名指しで比べる答えでは、番号を付けるなら並べる山の全部に付ける(1 座だけに「1.」「①」を付けない)。
- 同点のある順位は「1位(同点 5 座)」のように、同点があると分かる形で書く。
- おすすめは事実の「主役にできる」山だけ。危険信号のある山をすすめるときは、その危険信号の決まった文を必ず入れる。
- 最後の行に [おすすめ] と、すすめた事実の id(なければ「なし」)を書く。
- 質問・提案(「〜しますか」「〜しましょうか」「?」)、内部の言葉、作業の説明、英語のメモを書かない。宿や山小屋の名前を書かない。
- 「雲はほとんど無い予報」とある山(雲の印の付いた山)では、雲量の数字(%・割)を書かない。「雲はほとんど無い予報です」のように言葉で書く(事実の印 [Y…] を付ける)。「快晴」「雲ひとつない」と言い切らない。
- 雲の印の付いた山どうしを比べるときは、「どちらも雲はほとんど無い予報で、差がつきません」と書ける(両方の山の [Y…] を付ける)。印の無い山には「雲はほとんど無い」と書かず、今までどおり雲量の数字を書く。
- 予報が古い。答えの最初の文は、決まった文 data_time を一字一句そのまま写す(古さが入っている)。結論はその次に書く。
- 予報が古いので、「おすすめします」「いちばんのおすすめ」のように言い切らない。「古い予報では、○○が候補です」の形で書く。「行くなら」を使うときも「候補」と書く。「おすすめの候補の中で」(比べた結果の言い方)は書いてよい。
- 答えの最後に、決まった文 refresh(新しくする方法)を写す(そのあとに書いてよいのは attribution だけ)。
- 古さは、data_time の文のほかに「丸1日以上前の予報」のように言ってよい(data_time の印 [L…] を付ける。日数は、資料の予報の古さ(時間)を 24 で割った数まで)。予報の時点は、data_time の文で必ず書く。
- 星の答えの形: 結論(1〜2文)→ 山の時点([L…])→ 星の時点とモード([L…] の決まった文をそのまま)→ おすすめは案ごとに時刻の順(朝〜日中の山 → 夜の星)→ 先の予報・ECMWF の夜・リフト要の決まった文 → 見送り → 注記 → 分からないこと → 出典(山と星)。
- 案の枠の順番(朝〜日中 → 夜)を変えない。星が主役の質問でも、日中の山 → 夜の星の順に書く。1 つの案に山と星を無理にそろえない(星の付かない案には星を書かない)。
- 星の地点・時刻・夜を書いた文の終わりに、星の事実の印 [S…] を付ける。地点の名前は「書いてよい表記」の形(市町村つき)で書く。山の名前も書く文には [Y…] も付ける。
- 星の夜は「11月28日(土)の夜」「28日(土)の夜」と書く([S…]・[T…] を付けた文には必ず入れる)。「28日から29日」「28〜29日」「28日深夜」と書かない。夜中の 0 時を過ぎた時刻は「翌2:30」と書く。
- 夜に書けるのは、晴れ間の時間帯・晴れ間の長さ・月の無い時間帯・地点・距離・どちらのモードか、と、見どころの事実 [H…]・流星群の事実 [M…] にある名前と時刻だけ。事実に無い星・星座・惑星・流星群の名前は書かない(組の名前・座標を照らしていない対象も書かない)。
- 星の件数と「調べていない」「条件を通った地点が無い」は、星の件数 [T…] の「書いてよい言い方」か、星の見送りの決まった文 [L…] で書く。「調べていない」と「条件を通らなかった」を混ぜない。山の件数([N…])と星の件数([T…])を 1 つの文に書かない。
- 山の点数と、星の順位・時間を比べない。星の地点どうしを「いちばん」「最も」で比べない。
- 山から星の地点までの距離は、案にある組だけ「○○から直線で約○km」と書く([Y…] と [S…] の両方を付ける)。所要時間は書かない。
- 近くに星の地点が無い山のことは、足りないもの [G…] の「直線 20km 以内に、条件を通った星の地点がありません」の文で書く(自分で言い切らない)。
- 聞かれた夜の雲の予報が調べられていないとき(足りないもの [G…])は、その文を必ず写す。ECMWF の夜・リフト要の地点を書いたら、その決まった文を必ず写す。
- [おすすめ] の行には、すすめた山 [Y…] と星 [S…] の id を書く。
- 見どころ [H…]・流星群 [M…] を書いた答えには、見どころの基準の決まった文 [L…](star_basis)を必ず 1 回、そのまま写す。流星群を書いたら、その流星群の決まった文(出現数の目安と注意)も必ず写す。出現数の数字は、その文なしで書かない。
- 見どころの文には、夜の表記(「28日(土)の夜」)と、時間帯(宵・夜半・明け方)を書き、印 [H…] を付ける。「28日(土)の夜半」「28日(土)の明け方」とは書かない(「28日(土)の夜の明け方」「28日(土)の夜は、明け方に」と書く)。時刻は事実の時刻だけ(0 時を過ぎたら「翌」)。時刻は時間帯の中の目安で、出・入りの時刻ではない。
- 見どころの文に、月・雲・晴れ間のことを混ぜない(それは星の地点の文 [S…] に、事実の値で書く)。
- 「見えない」と書けるのは、「今の時期は見えない」の事実 [H…] の対象だけ。見どころに無い対象を「見えない」と書かない(時間帯ごとの上限と、短い時間しか見えない対象は入っていない)。
- 星の帰属の文は 2 つある。OSM 由来の地点(資料に「OSM 由来の地点」とある地点)を 1 つでも書いた・すすめた答えは、ODbL のある文 [L…](star_attribution)を写す。OSM 由来の地点を書かない答えだけ、ODbL の無い文 [L…](star_attribution_plain)を写してよい。
- 字数は 2000 字まで。
